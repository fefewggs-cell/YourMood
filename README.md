# 🌈 Your Mood

**Your Mood** es una aplicación desarrollada en **MIT App Inventor** enfocada en el registro de estados de ánimo y la consulta de información relacionada con las emociones seleccionadas por el usuario.

## 💡 Sobre el proyecto

Este proyecto fue desarrollado para continuar practicando la creación de aplicaciones que trabajan con información generada directamente por el usuario.

La idea principal consiste en proporcionar una interfaz sencilla en la que una persona pueda identificar y registrar cómo se siente, utilizando diferentes opciones de estados de ánimo.

Además de trabajar con la captura de información, el proyecto incorpora una forma de consultar los registros realizados, permitiendo conectar diferentes partes de una aplicación para crear una experiencia más completa.

## ⚙️ ¿Cómo funciona?

La aplicación presenta diferentes opciones que representan estados de ánimo. El usuario puede interactuar con ellas para indicar cómo se siente y generar un nuevo registro.

El proyecto también cuenta con una sección destinada a consultar la información registrada, separando la captura y la visualización de los datos dentro de la aplicación.

La navegación entre estas secciones permite trabajar con una estructura más organizada y demuestra cómo distintas pantallas o elementos de una aplicación pueden colaborar utilizando información generada por el usuario.

## 🌱 Lo que aprendí

Your Mood me permitió practicar cómo diseñar una aplicación alrededor de información seleccionada directamente por el usuario.

También reforcé la importancia de organizar una aplicación en diferentes secciones según su función, separando el proceso de registrar información del proceso de consultarla.

Este proyecto forma parte de mis prácticas con MIT App Inventor y contribuyó a desarrollar una mejor comprensión de la relación entre la interfaz, los eventos y los datos dentro de una aplicación móvil.
